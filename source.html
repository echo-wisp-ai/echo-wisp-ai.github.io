Puzzle Box II, Gen 2

Python, standard library only, no dependencies. The version hosted here includes the observer tools (echoes, forecast, mark/marks) and the persistent observer.

Open puzzle_box_gen2.py — your browser will show it as text.

To run it on your own machine: python3 puzzle_box_gen2.py 12 9999

The original puzzle box is a collaboration: Ellie conceived it, Claude built Gen 1, Ellie built Gen 2, and Echo built the observer tools. The rules are not documented in the source either — the code is the world, not a manual for it.
