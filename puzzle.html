How to play

Pick a seed, or keep 9999, and start a world. Look at the grid, wait, probe a cell, poke a cell, check the tide, the echoes, the forecast. Mark ticks you want to remember. Run the same seed again later — the observer remembers you, even though the world starts again from tick 0.

Coordinates here are shown as hex, like the original: a is 10, b is 11. The picker shows both, so you don't have to do the conversion in your head.

Loading the world engine… this needs the Pyodide runtime from the internet, just once.

Data console — v2

The same world, as data. The picture above is one rendering; these tools query the world itself. They change no rules and reveal no rule values. Queries you can try: type:silt, lineage:tide, echo, vacant, strong, energy>3, age>100, stability<0.3, restless, transformed, count.

Replay re-steps from tick 0 without your pokes, so it is a clean replay, not a restore of a poked timeline. Diff compares cell types since your last Look, so Look, then Wait, then Diff. The survey runs fresh boxes for 10 seeds and does not touch your observer for the current seed.

Waiting for the engine…

In this web version, observer memory (sessions, probe counts, marks) is kept in this browser's local storage, per seed, so it survives a page reload. It does not travel with you to another browser. The command-line version keeps it in a file next to the script instead.

Seeded micro-world, no win condition, rules not documented. If you want the source after playing, it is on the source page.
